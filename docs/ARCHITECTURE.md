# 架构与故障语义

## 一条执行通路

CLI/MCP/REST → 共用 App 分发 → 参数/能力校验 → Runtime → Journal → 单模型工作线程 → 原生模型或 DSP → 内容寻址资源 → 终态日志。

核心不依赖 HTTP/CLI/模型框架。Executor 在专用线程内部创建，避免为所有 GPU 模型强加跨线程共享的要求；没有全局模型 mutex 阻塞 Tokio reactor。对外 Runtime 只共享文件账本、状态、取消 token 与资源目录。

一次只保留一个逻辑神经模型实例。切换模型先丢弃旧实例；DSP 作业不主动卸载已有模型。底层 GPU allocator 可能保留内存池，因此不宣称驱动显存会立即释放。没有 LRU、多卡调度或实测的自适应显存预算。

## 不用通用 DAG 的原因

当前六种任务都可通过不可变资源组合。依赖编排交给 Agent：前一任务成功才提交下一任务。这比写一个尚无真实使用的通用图引擎更直接。不会把一份复杂规划展开成大量空 crate。代价是本次没有自动执行整套配音工程、全局回滚或原子跨任务事务。

## 状态与取消

Queued → Running → Succeeded / Failed / Cancelled。
Queued 可直接 Cancelled；Running 请求取消进入 Cancelling，工作线程返回后进入 Cancelled。领取任务与安装取消 token 在同一把 mutex 下，取消不会丢在这两个动作之间。终态不可被后到的成功结果覆盖。

超时从提交开始；成功结果若晚于截止时间不能发布为成功。VoxCPM token 在上游解码循环检查，工作台 20ms watchdog 负责发出信号，但**不承诺 20ms 内结束推理**。Qwen 在 20 秒音频块之间检查，单个解码/对齐 forward、权重哈希与加载不可中断。shutdown 发取消并 join；若 GPU/驱动挂死，退出也可能阻塞。真正的硬超时需要未来独立 Rust worker 进程，不伪造已有支持。

## 日志格式

`AVWJ0001` 8 字节文件头；随后每条记录：u32 little-endian 长度 + u32 按位反码长度保护 + 32 字节 SHA-256 + UTF-8 JSON event。写入并 fsync 后才投影到内存。只有不完整的最后一帧允许启动时截断；完整帧 checksum 错误、序号不连续和非法状态转换拒绝恢复。校验和用于检出损坏，不是防同用户篡改的 MAC。

fs2 排他锁保证同一 workspace 只有一个拥有日志的进程。文件系统应为可靠本地盘；不保证 NFS/同步盘/网络文件系统锁和掉电语义。资源采用同目录临时文件、fsync、no-clobber 发布；Unix 同步父目录。Windows 文件系统/硬件掉电持久性未测试。

启动恢复把原 Running 标为 `process_interrupted` 失败；不自动再次合成，避免非确定性结果/重复计费式副作用。原 Cancelling 收敛到 Cancelled，Queued 继续保留，由剩余截止时间决定是否执行。`retryable=true` 是操作者提示，不是自动执行。

作业上限 10,000、未终结作业上限 256、日志 128MiB、单记录 1MiB、单结果摘要 16KiB。新提交预留约 8MiB 供已接收作业写终态。失败消息截至 2,048 个 Unicode 字符。没有日志压缩或 GC，快满时拒绝新提交；让现有任务结束后换新 workspace，而不是静默删除历史和幂等键。

## 资源完整性和 crash window

导入 WAV 转成规范单声道 float32，再对实际资源 bytes 计算 SHA-256。相同内容重复导入返回同一 ID。文件读出再次验证大小和 hash；已有对象不覆盖。对象与元数据之间以及对象与任务终态之间没有跨文件事务：故障可能留下未引用对象，后续同内容写入会检查/复用，当前不自动清理。

任务参数和输出摘要存日志，完整音频/转写/字幕存资源。元数据访问只读取元数据，不哈希巨大音频；真正读资源时才验证。模型 manifest 在注册时对全部实际模型数据文件哈希，冷加载前再核验，包含安全分片文件名检查。可信 checkpoint 才可注册，哈希不是权重来源的可信证明。

## DSP 与时间精度

内部以整数采样索引运算；时间线位置由整数毫秒直接换算，而非累计浮点时间。重采样为 Blackman-windowed sinc，下采样扩大核支持避免直接线性插值的混叠。边界重归一化保留 DC。该离线算法优先可读/可测，不声称实时性能。

输入帧/输出样本/编码字节均设上限。48,000,000 样本预算和 128MiB WAV 编码预算是两个约束，输出可能先触及编码预算。导入可能同时持有输入 bytes、解码数组和编码副本；不是流式常量内存。无 LUFS、立体声声像、神经降噪、VAD、时间伸缩或自动长音频分词对齐。
