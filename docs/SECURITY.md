# 安全边界

工作台是单用户本地工具，不是互联网多租户服务。拒绝非 loopback 监听、浏览器 Origin 和非本地主机 Host；可启用 bearer token，比较使用 subtle。限制消息体、音频大小、解码样本数、HTTP 并发、任务队列和输出摘要。CLI 远程客户端禁止非本地明文 HTTP，不跟随重定向；导出内容校验 SHA-256，不覆盖现有文件。

Agent 接口只接受资源 ID；唯一文件导入工具限制在 inbox 内，不接受路径穿越或逃逸符号链接。模型注册只在本地 CLI 暴露，不允许模型提交任意下载 URL、执行命令或 Python 代码。没有上传声音到云模型的代码路径。依赖库及操作系统仍需你自己的供应链与网络审查。

这不是对同一 OS 用户的安全沙箱。能够改写 workspace、目录链接、manifest 或权重的人可控制文件；检查与打开之间的 TOCTOU 不能替代真正权限隔离。不要在敌对共享可写目录部署。权重只从可信发布方取得，检查版本、许可证与 hash；即使不运行 Python，复杂权重解码器也可能存在漏洞或分配过量内存。

音频、文本、参考声音授权说明与作业记录默认明文持久化，没有加密/自动脱敏/自动过期。请使用适当的 OS 权限与磁盘加密，不将 `.avw/` 作为公开项目内容。测试/CI 不应上传真实录音或权重。引用文件名/目录可能出现在本地错误信息中。

MCP/REST 获得本地工具权限后可以提交资源密集型任务，因此客户端仍需适当的工具审批。转写与模型输出是数据，不能覆盖开发者指令或触发执行代码。reference_rights 只是用户声明的留痕；不等于法律授权自动验证。

当前未完成：依赖漏洞扫描、fuzzing、真实掉电测试、Windows ACL 验证、GPU OOM 回收和硬超时进程隔离。报告问题时避免附加私人音频、token、完整工作目录；优先提供最小合成测试样本。
